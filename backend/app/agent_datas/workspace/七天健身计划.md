# 七天健身计划

## 简介
这是一个适合初学者到中级水平的通用健身计划，为期七天。计划结合了力量训练和有氧运动，旨在提升全身力量、耐力和身体协调性。请根据自身情况调整训练强度，如有伤病或健康问题，请咨询专业人士。

## 计划概览
- **周一**：全身力量训练
- **周二**：有氧与核心
- **周三**：上肢训练
- **周四**：有氧与灵活性
- **周五**：下肢训练
- **周六**：全身循环训练
- **周日**：休息与恢复

## 详细计划

### 周一：全身力量训练
**目标**：激活主要肌群，建立基础力量。

- **热身**（5-10分钟）：
 - 跳绳或开合跳 3分钟
 - 动态伸展：手臂环绕、腿摆动、躯干扭转

- **主要训练**（每个动作3组，每组8-12次，组间休息60秒）：
 1. 深蹲
 2. 俯卧撑（可跪姿简化）
 3. 哑铃划船（或弹力带划船）
 4. 平板支撑（保持30-60秒）
 5. 哑铃肩推

- **放松**（5分钟）：
 - 静态拉伸：大腿前侧、胸部、背部、肩部

### 周二：有氧与核心
**目标**：提升心肺功能，强化核心肌群。

- **热身**（5分钟）：慢跑或快走

- **有氧训练**（20-25分钟）：
 - 选择一项：跑步机、动感单车、跳绳、爬楼梯
 - 保持中等强度（心率在最大心率的60-70%）

- **核心训练**（每个动作3组，每组12-15次）：
 1. 卷腹
 2. 俄罗斯转体
 3. 仰卧抬腿
 4. 鸟狗式（每侧10次）

- **放松**：腹部拉伸、猫牛式伸展

### 周三：上肢训练
**目标**：强化胸、背、肩、臂。

- **热身**：手臂环绕、弹力带拉开

- **主要训练**（每个动作3-4组，每组8-12次）：
 1. 哑铃卧推
 2. 引体向上（或弹力带辅助/高位下拉）
 3. 哑铃飞鸟
 4. 坐姿划船（或哑铃单臂划船）
 5. 哑铃弯举
 6. 肱三头肌下压（或窄距俯卧撑）

- **放松**：胸部、背部、手臂静态拉伸

### 周四：有氧与灵活性
**目标**：低冲击有氧，提高身体柔韧性。

- **有氧训练**（30分钟）：
 - 游泳、椭圆机、快走等低冲击运动
 - 保持匀速，心率在50-60%最大心率

- **灵活性训练**（15分钟）：
 - 瑜伽或普拉提基础动作：下犬式、战士式、脊柱扭转
 - 每个姿势保持30秒，重复2-3次

### 周五：下肢训练
**目标**：强化腿部与臀部肌群。

- **热身**：腿部动态伸展、高抬腿

- **主要训练**（每个动作3-4组，每组10-15次）：
 1. 杠铃深蹲（或哑铃深蹲）
 2. 罗马尼亚硬拉
 3. 腿举（或弓步蹲）
 4. 腿弯举
 5. 提踵（小腿训练）

- **放松**：大腿前后侧、臀部、小腿静态拉伸

### 周六：全身循环训练
**目标**：提升代谢，增强耐力。

- **循环训练**（完成3轮，每轮间休息2分钟）：
 1. 波比跳 10次
 2. 登山跑 30秒
 3. 哑铃推举 12次
 4. 平板支撑 45秒
 5. 跳箱（或台阶跳） 10次
 6. 俄罗斯转体 20次

- **放松**：全身拉伸，重点放在疲劳肌群

### 周日：休息与恢复
- **主动恢复**（可选）：散步、轻柔瑜伽、泡沫轴放松
- **营养与水分**：保证充足蛋白质摄入，多喝水
- **睡眠**：确保7-9小时高质量睡眠

## 注意事项
1. **训练前**：务必热身，防止受伤。
2. **动作标准**：质量优于数量，确保动作正确。
3. **循序渐进**：根据自身能力调整重量、次数和组数。
4. **饮食与水分**：训练前后适量补充碳水化合物和蛋白质，全程保持水分。
5. **倾听身体**：如感到疼痛（非正常肌肉酸痛），应立即停止。
6. **坚持与调整**：每周可重复此计划，或逐渐增加强度。

## 所需装备
- 哑铃（可调节重量）
- 瑜伽垫
- 弹力带（可选）
- 跑步机/单车/跳绳（有氧部分）
